This script is a recreataion of the classic arcade game "Space Invaders"


If running on a MAC, install the 'requirements.txt' file and run the script space_invaders.py.
However, if running on Windows, please also install the module 'msvcrt' as the way that MAC and Windows terminal reads keyboard inputs is different.

I've added two extra python files, space_invaders_OOP.py and space_invaders_game.py. This is another recreation focusing on coding the game with Object-Oriented-Programming. The classes are store in the space_invaders_OOP.py and the actual game is played by running space_invaders_game.py.
